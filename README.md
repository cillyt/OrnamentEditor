# Опис можливостей
## Розроблений редактор орнаменту надає користувачеві змогу зручно створити власну схему вишивки. 
На головному екрані розташовані інструкція щодо використання програмою, кнопки виходу та відкриття редактору.

Одразу після відкриття редактору генерується орнамент імені «Анна» з можливістю його редагування. 

Користувач інтерактивно може змінювати кількість клітинок на полотні, за допомогою спінера зі стрілками, зберігаючи при цьому попередньо намальований малюнок, обирати кольори з палітри, тип симетрії, де симетричні хрестики вимальовуються відповідно до намальованих власноруч, та дублювання, де автоматично дублюється вже сформований візерунок. 

Також користувач може коригувати намальований орнамент за допомогою перемикача «очистити клітинку», увімкнувши який можна видалити один хрестик.

Після натиснення на кнопку «Очистити полотно», візерунок повністю стирається без можливості відновлення та залишає пусте полотно.
  
У верхньому меню доступні додаткові можливості, а саме знову відкрити іменний орнамент, зберегти намальований орнамент у форматі .png, завантажити раніше збережений орнамент та переглянути інструкцію.
